# PPMM - Python Pip Mirror Manager

🌟 **PPMM** 是一个强大的命令行工具，用于管理 Python 包管理器（pip）的源。它能让你轻松列出、切换、测试 pip 源，还能添加、修改、删除和重命名源。

**简体中文** | [English](./README.en.md)

## 安装

🚀 使用 pip 安装 PPMM：

```bash
pip install ppmm
```

## 使用

- 📝 使用 `mm ls` 快速列出可用源
- 🔗 使用 `mm use <name>` 轻松切换源
- ⏱️ 使用 `mm test` 测试源的响应时间
- 🎯 使用 `mm current` 显示当前使用的源
- ➕ 使用 `mm add <name> <URL>` 添加新源
- ✏️ 使用 `mm edit <name> <URL>` 修改指定源
- ❌ 使用 `mm rm <name>` 删除指定源
- 🔁 使用 `mm rename <old name> <new name>` 重命名源
- ℹ️ 使用 `mm help` 显示帮助信息
